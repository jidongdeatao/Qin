# 现代瑜伽技术安全学习地图

## 建议顺序

1. **体式与呼吸觉察**：先建立稳定、无痛的基础动作和自然呼吸。
2. **基础调息**：从延长呼气、均匀呼吸开始，不以憋气时长作为进步标准。
3. **专注与冥想**：从短时、可停止的练习开始，逐渐观察身体与情绪反应。
4. **深度放松与休息术**：在安全环境中练习，避免开车或操作设备时使用引导音频。
5. **进阶清洁术、收束法和手印**：必须理解禁忌证，并向具备相应训练的教师学习。

## 立即停止练习的信号

- 胸痛、晕厥、明显呼吸困难或持续心悸；
- 关节锐痛、麻木、失去力量或疼痛向肢体放射；
- 强烈恐慌、解离、失眠加重或精神状态显著改变；
- 清洁法后持续出血、呕吐、腹痛或感染迹象。

出现严重症状时应及时寻求医疗帮助。孕期、近期手术、青光眼、未控制高血压、心血管疾病或严重心理健康问题人群，应在练习前咨询合格医疗专业人员。

## 阅读技术说明时要问

- 资料是否写明作者、传承、适用人群和禁忌证？
- 动作是否提供初级版本、退出方式和替代方案？
- “排毒”“治愈”“激活”等说法是否有可靠证据？
- 研究中的具体技术、频率和人群是否与当前练习相同？

本站的技术资料用于教育与文献整理，不构成诊断、治疗或个体化训练处方。
