# 《哈他瑜伽灯论》导读摘录

> 来源说明：Hatha Yoga Pradīpikā 为中世纪哈他瑜伽重要文献，本篇为公有领域传统内容的结构导读与要点摘录。

## 文献概览

传统归于 Svātmārāma。常见四章结构：

1. 体式（Āsana）
2. 调息与生命能量（Prāṇāyāma / Kumbhaka）
3. 泥印与收束（Mudra / Bandha）
4. 声音与禅定（Nāda / Samādhi）

## 核心主张（导读）

- 哈他是通往王瑜伽的阶梯：先稳定身体与气息，再进入心识修持
- 强调身体净化、呼吸长度与神经系统的准备
- 反对空洞炫技：技术服务于觉醒与健康

## 常见主题词

- 六种净化法（ṣaṭkarma）
- 收束：mula / uḍḍīyāna / jālandhara
- 中脉与气脉象征语言（需以历史语境理解，不宜简单生理化）

## 现代阅读注意事项

1. 古典文本含隐喻与时代医学观念，需与当代解剖/医学对照
2. 高阶调息与收束应在合格教师指导下练习
3. 可与本站「瑜伽解剖学」「瑜伽生理学」交叉阅读

## 实践安全清单

- 避免憋气过长、眩晕时强行继续
- 怀孕、高血压、青光眼等情形需专业评估
- 先建立稳定体式与自然呼吸
