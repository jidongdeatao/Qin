# 瑜伽古典文本阅读地图

## 使用说明

古代原典本身通常不受现代著作权保护，但译文、注释、排版、校勘和数字版本可能拥有独立版权。本资料库优先链接明确标注 Public Domain 的历史版本；引用或转载前，仍应检查来源页的权利声明。

### 关于中文版本

目前可可靠核验为公共版权的资料主要是梵文原典与早期英文历史译本。多数常见中文全译本出版较晚，仍可能受译者著作权保护，因此本站不会仅因“网上可以下载”就复制全文。中文栏目会区分：

- **公共版权**：来源页明确标注 Public Domain；
- **开放获取**：权利人或机构允许在线阅读，但不一定允许重新发布；
- **参考资料**：可用于检索和比较，转载须遵守原站许可。

若后续取得中文译者或出版社书面授权，可再将授权文本作为本地资料归档。

## 四条入门路径

### 《瑜伽经》Yoga Sūtra / योगसूत्र

- 核心问题：心识如何运作？练习与离欲如何导向辨识与自由？
- 推荐顺序：四章结构概览 → 梵文关键词 → 单条经文与注疏对读。
- 重要术语：yoga、citta、vṛtti、nirodha、abhyāsa、vairāgya、samādhi、kaivalya。

### 《奥义书》Upaniṣads / उपनिषद्

- 核心问题：自我（ātman）、终极实在（brahman）、生命气息（prāṇa）与觉知是什么关系？
- 推荐顺序：主要奥义书选读 → 瑜伽奥义书 → 不同时期文本的观念比较。
- 注意：奥义书并非一本单一著作，各文本年代、传统和教义重点不同。

### 《薄伽梵歌》Bhagavad Gītā / भगवद्गीता

- 核心问题：人在行动、知识与奉爱之间如何实践瑜伽？
- 推荐顺序：叙事背景 → 业瑜伽 → 智瑜伽与禅瑜伽 → 奉爱瑜伽 → 全篇结构。
- 阅读原则：区分原文、译者选择与宗派注释，不将某一译本视为唯一解释。

### 《哈他瑜伽之光》Haṭha Yoga Pradīpikā / हठयोगप्रदीपिका

- 核心问题：身体、呼吸、收束、手印与三摩地如何构成哈他瑜伽路径？
- 推荐顺序：历史语境 → 四章结构 → 与《格兰达本集》等文本比较。
- 安全提示：经典对清洁术、屏息、收束法的描述是历史文献，不是面向所有人的现代操作指南；进阶技术需合格教师现场指导。

## 版本核验清单

1. 记录作者、译者、注释者、出版者和出版年份。
2. 检查来源页是否明确标注 Public Domain、CC 授权或其他许可。
3. 古籍扫描可公开访问，并不自动代表允许重新分发。
4. 梵文转写应注明 IAST 或天城体版本，并保留校勘差异。
5. 中文译文若非自行翻译，应确认译者去世年限及所在地法律。
